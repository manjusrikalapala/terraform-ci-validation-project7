## Overview

This project demonstrates Continuous Integration (CI) validation for Terraform using GitHub Actions.

## CI Checks

- Terraform Format Check (`terraform fmt`)
- Terraform Initialization (`terraform init`)
- Terraform Configuration Validation (`terraform validate`)

## Workflow

Every push to the main branch automatically triggers the GitHub Actions workflow, ensuring Terraform code quality and validity before deployment.

## Technologies Used

- Terraform
- GitHub Actions
- Git
- Linux
